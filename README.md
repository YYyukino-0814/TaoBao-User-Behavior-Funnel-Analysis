# 淘宝用户行为 · 交易漏斗分析

用 **1000 万条**淘宝用户行为日志（原始 1 亿行 / 3.67 GB），把「浏览 → 加购 → 购买」
这条链路上的每一步查清楚，并**推翻三条听起来很对、但数据不支持的常识**。

| | |
|---|---|
| 数据来源 | Kaggle / 阿里天池「User Behavior Data from Taobao」 |
| 数据规模 | 原始 1 亿行（3.67 GB）→ 分析样本 **1000 万行** |
| 分析窗口 | 2017-11-25 ~ 2017-12-01（7 天） |
| 分析对象 | 99,020 个用户、158.8 万件商品、8,044 个类目 |
| 主要工具 | **DuckDB + SQL**（取数）、Python + Matplotlib（画图） |
| 产出 | 9 组 SQL、20 张结论图、10 篇分析文档、4 张看板聚合表 |

---

## 一、三条被推翻的常识

| 常识 | 数据说的 |
|---|---|
| ① 资源该押给重度用户 | 重度用户拿走 **68% 的流量**，只产出 **53% 的成交**；单位行为购买产出 2.02（轻度）vs 0.78（重度） |
| ② 加购是转化扳机，催加购最有效 | 加购之后下一步成交概率 **0.88%**，**比随机挑一个非购买动作的平均 1.17% 还低** |
| ③ 晚上加购最多，是黄金时段 | 加购渗透率 22–23 点最高（31.21%），但**加购者购买率最低**（38.90%）；双高点在**上午 10 点** |

**最后一个结论是整份分析的落点**：加购商品只有 **6.21%** 被同一人买回、
**78%** 的加购成交发生在**会话结束之后**——所以**购物车不是待付款清单，是意向标记**。
「在加购当下催单」这个常见动作方向是错的，正确做法是在之后的会话里把它重新送到用户面前。

## 二、分析主线（S1–S10）

| 步 | 干什么 | 一句话结论 |
|---|---|---|
| S1 | 认识数据 + 四种行为占比 | 浏览约占九成，全站天然逛多买少 |
| S2 | **交易漏斗主线** | 两步通过率几乎一样，**没有卡点**；购物车是比价清单 |
| S3 | 时间规律（小时分布） | 加购的含金量 10 点 62.81% vs 23 点 39.29%；顺带查实 12-02 的数据异常 |
| S4 | 日活留存 | 回访率几乎不衰减（D1 74.90% → D3 73.12%），因为用户本来就天天来 |
| S5 | 复购分析 | 复购口径有构造重叠陷阱，拆开后结论完全不同 |
| S6 | 类目转化差异 + 卡方 | 差 20.6 倍，但 **Cramér's V 只有 0.13**；依据是跨天排序稳定性，不是 p 值 |
| S7 | 轻 / 中 / 重度分层 | **重度用户 68% 流量只产 53% 成交**；「活跃」≠「买单」 |
| S8 | **行为路径 / 序列** | 66.37% 的会话是纯浏览；**加购后成交 78% 在会话外** |
| S9 | **加购召回测算** | 93.79% 沉默；一半的人握 84.47% 的机会；最大档是 6~24 小时 |
| S10 | 汇总动作建议 + 看板聚合表 | 见 `分析文档/10_结论与行动建议.md` |

**S8 / S9 是整个项目里最花功夫的部分。** 常见同款分析普遍只做到 S7
（占比、趋势、分布），这两节做的是「用户实际走的路径」和「能交给运营的动作 + 情景测算」。

### 三条动作建议

1. **加购召回的时点从「加购当下」推到「次日上午」**——名单发 D 层 32,942 人
   （握 84.47% 的沉默件），站内可触达 89.21%（下界），每提升 1 个点 = 3,650 件，
   **提升幅度必须靠 A/B 实验验证**。
2. **KPI 按类目定**，依据是排序的跨天稳定性（Spearman 中位 0.93，Top 10 重合 10/10），
   **不是 p 值**——61 万配对下 p 值没有决策价值。
3. **别把「高活跃」当「高价值」**——逛型要短决策路径，买型要高频次回访，两类人策略方向相反。

## 三、口径与局限（读结论前请先看这一节）

- **这份数据不是全站流量。** 7 天窗口内 **58.04% 的用户有购买行为**，
  真实电商只有个位数——说明这是**筛选过的活跃 / 购买倾向人群**。
  所以本项目的结论**只讲相对结构（哪一步掉得狠、哪群人更容易转化、高峰在几点），
  绝不外推绝对水平**。
- **没有金额字段**（也没有订单号、商品名、价格）→ 本项目**不做 GMV、不做客单价、不做 ROI**，
  测算只用件数和人数。
- **会话是自定的**：相邻行为间隔 > 30 分钟算新会话。所以会话数、人均会话数这类
  规模指标是**阈值相关**的，不能当固定事实（已做 15/30/60 分钟三档稳健性检验）。
- **窗口只有 7 天**：所有跨期转化率都做了截断检验，但只能声明方向，测不出真实比例。
- **全部是描述性分析**，不做因果推断；「加购的人沉默率高」不等于「加购导致沉默」
  （选择效应）。

完整的口径定义、异常处理与局限声明见 [`00_口径与数据说明.md`](00_口径与数据说明.md)。
