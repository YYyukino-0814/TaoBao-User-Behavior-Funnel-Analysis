# 淘宝用户行为 · 交易漏斗分析

用 **1000 万条**淘宝用户行为日志，把「浏览 → 加购 → 购买」这条链路上的每一步查清楚，
并推翻三条听起来很对、但数据不支持的常识。

## 快速了解

| | |
|---|---|
| 数据来源 | Kaggle / 阿里天池「User Behavior Data from Taobao」 |
| 数据规模 | 原始 1 亿行（3.67 GB）→ 分析样本 **1000 万行** |
| 分析窗口 | 2017-11-25 ~ 2017-12-01（7 天） |
| 分析对象 | 99,020 个用户、158.8 万件商品、8,044 个类目 |
| 主要工具 | **DuckDB + SQL**（取数）、Python + Matplotlib（画图） |

## 三个最重要的发现

| 常识 | 数据说的 |
|---|---|
| 资源该押给重度用户 | 重度用户拿走 **68% 的流量**，只产出 **53% 的成交** |
| 加购是转化扳机，催加购最有效 | 加购之后下一步成交概率 **0.88%**，**低于随机挑一个非购买动作的 1.17%** |
| 晚上加购最多，是黄金时段 | 加购成交量在 22–23 点最高，但**加购者购买率最低**；双高点在**上午 10 点** |

**落点**：加购商品只有 **6.21%** 被同一人买回、**78%** 的加购成交发生在**会话结束之后**
——所以**购物车不是待付款清单，是意向标记**。

## 三条行动建议

1. **加购召回的时点从「加购当下」推到「次日上午」**——名单发 D 层 32,942 人
   （握 84.47% 的沉默件），每提升 1 个点 = 3,650 件，**提升幅度须由 A/B 验证**。
2. **KPI 按类目定**，依据是排序的跨天稳定性（Spearman 中位 0.93，Top 10 重合 10/10），
   **不是 p 值**。
3. **别把「高活跃」当「高价值」**——逛型要短决策路径，买型要高频次回访。

## ⚠️ 读结论前先看这三条

- **这份数据不是全站流量。** 7 天窗口内 **58.04% 的用户有购买行为**，真实电商只有个位数。
  所以结论**只讲相对结构，绝不外推绝对水平**。
- **没有金额字段** → 不做 GMV、不做客单价、不做 ROI，测算只用件数和人数。
- **会话是自定的**（相邻行为间隔 > 30 分钟）→ 会话类指标是阈值相关的，已做三档稳健性检验。

完整口径、异常处理与局限见 [`00_口径与数据说明.md`](00_口径与数据说明.md)。
